# Hinge-Hot-Takes-Text-Mining-Social-Insights
A data-driven analysis of 700+ controversial opinions from LA Hinge users (ages 19–24). This project structures raw conversations into a categorized dataset to explore social themes, trends, and narratives young adults express in digital spaces.

Overview:
- This project transforms raw Hinge conversations into a structured, analyzable dataset. Each response is categorized into themes such as politics, dating, ethics, social norms, stereotypes, conspiracy theories, and more.
- The goal is to examine what young adults consider “controversial,” identify social patterns, and explore trends across opinion categories.
- This project combines data science, journalism, and social analysis.

Categories:
Each response is coded into one of the following categories:
1. Food opinion
2. Political
3. Gender/Dating
4. Social Norms
5. Entertainment/Lifestyle
6. Ethics/Morality
7. Religion
8. Conspiracy Theory
9. Humor/Joke
10. Sports
11. Social Bias/Stereotype
12. Flirting
13. Education
14. Outlier/Doesn't Fit

Data Cleaning:
- Removing identifiers (names, profile info)
- Standardizing text format
- Assigning categories through manual coding
- Tagging response metadata (age, date, location, method)
Dataset is fully anonymized and compliant with ethical data collection standards

Analysis Plan: 
- Distribution of categories
- Word frequency + text mining
- Comparisons across age groups
- Sentiment patterns
- Cluster analysis of social themes
- Vizualizations
Future phases will include cross-city comparisons (e.g. Austin, Denver, NYC).

Journalism Angle:
- How young adults define "controversial"
- How anonymity affects honesty
- Which opinions are joked about vs. serious
- Which topics are culturally sensitive
- How social narratives shift across cities and demographics
